# Romantic Gift Page (GitHub Pages)

Мини-проект-сюрприз: романтичная страница с пиксельной мини-игрой из 2 уровней и финальным скачиванием подарка.

## Что внутри

- Стартовый экран с романтичным сообщением
- Мини-игра на сетке (вид сверху)
- 2 уровня, включая логическую задачку с рычагами и воротами
- Сбор сердечек + заблокированный финиш до полного прогресса
- Финальный экран с кнопкой скачивания `certificate.png`

## Структура файлов

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `certificate.png` (положить рядом с файлами)

## Локальный запуск

1. Убедитесь, что `certificate.png` лежит в той же папке, что и `index.html`.
2. Откройте `index.html` в браузере.

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите файлы проекта в корень.
2. В GitHub откройте `Settings` -> `Pages`.
3. В `Source` выберите `Deploy from a branch`.
4. Выберите ветку (обычно `main`) и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

После публикации сайт будет доступен по ссылке GitHub Pages, а кнопка скачивания будет вести на `certificate.png` по относительному пути.
